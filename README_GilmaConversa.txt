GILMACONVERSA
====================

Esta versão inclui:
- cadastro com foto de perfil obrigatória;
- login;
- conversas individuais;
- atualização automática das mensagens;
- envio de fotos e vídeos;
- visualização de imagens no chat;
- reprodução de vídeos no chat;
- criação de grupos;
- seleção de membros ao criar grupo;
- conversa dentro de grupos;
- painel simples de administração.

COMO INICIAR
1) Abra o PowerShell na pasta do projeto.
2) Execute: node server.js
3) Abra no Chrome: http://localhost:3001
